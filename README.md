# GlideCue Remote

用 iPhone 或 Apple Watch 遥控 Mac。iPhone 支持触控板、空中鼠标和远程桌面。

## 操作演示

[![GlideCue Remote 动态演示，点击观看视频](docs/glidecue-demo.gif)](docs/glidecue-demo.mp4)

[观看演示视频（18 秒）](docs/glidecue-demo.mp4)

## 快速开始

在 Mac 上打开接收端并允许蓝牙和辅助功能，再在 iPhone 或 Apple Watch 上选择这台 Mac 完成配对。要在 iPhone 上查看 Mac 桌面，请让两台设备接入同一局域网。

**系统要求**　iOS 18+、watchOS 11+、macOS 14+
