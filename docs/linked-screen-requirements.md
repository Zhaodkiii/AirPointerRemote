# GlideCue Remote · 屏幕联动需求

Linked Screen 已接入真实 Mac 屏幕、鼠标和文字输入。默认产品文案为英文。

## 当前实现与验收记录 · 2026-11-19

- 在 iPhone 17 Pro 和当前 Mac 的开发签名版本上，用户已确认通过 Wi-Fi 看到真实桌面、点选目标，并在「文本编辑」中自动打开手机键盘、插入中文。
- 默认使用系统显示器选择器确认一块屏幕。用户可以在 Mac 菜单栏为正在共享的已配对 iPhone 记住该显示器。再次共享时，已有屏幕录制权限且能唯一匹配到该活动显示器才直接采集。其他情况回到系统选择器。视频使用 ScreenCaptureKit 和 VideoToolbox H.264。Bonjour 定位当前配对设备为本次请求发布的临时服务；从蓝牙会话密钥和本次随机数派生 TLS-PSK，无需输入 IP。
- 当前实现使用一条全双工 TLS 连接。视频方向最多一帧待确认；编码忙时只保留最新采集帧。鼠标和文本沿反方向发送。拆分视频通道、动态码率和延迟目标由后续弱网实测决定。
- 聚焦检测只读取控件类型和可写属性。Mac 通过选区属性插入文字；无法确认控件时保留本地草稿。密码框和系统安全输入关闭自动联动。「插入」与目标应用的发送或保存是两个明确动作。
- 选择屏幕、拖动后松开、后台断线、锁屏清理、保持唤醒和恢复蓝牙鼠标均有代码路径。合盖外屏、较旧 macOS、多屏切换、弱网延迟和沙盒版本的跨应用输入仍需逐项实机测量。macOS 15.2 之前，在多个显示器中无法确认捕获目标时只开放查看。
- 本地验证入口为 `Tests/run-phone-checks.sh` 和 `Tests/run-linked-checks.sh`。后者在本机建立 TLS 连接、传输 Unicode 控制消息和真实编码帧、解码 H.264 并返回帧确认。

以下保留产品要求和验收目标。

## 1. 入口和会话

默认首页继续作为独立蓝牙鼠标。右上角的联动图标打开全屏页面，进入时释放拖动并暂停首页的空中控制。退出恢复原模式和暂停偏好。手表继续提供原有鼠标功能。正式版需由 Mac 仲裁当前输入设备，切换设备先释放所有按键。

首次使用路径为「选择已配对 Mac → 发现同一局域网服务 → Mac 同意本次共享并选择显示器 → iPhone 出现首帧 → 用户控制」。界面分别显示寻找 Mac、等待 Mac 确认、连接中、仅查看、可控制、已暂停。蓝牙已配对只代表认识该设备，Wi-Fi 可达性、屏幕授权和控制权限分别判断。访客网络隔离时提示两端接入可互访的网络；拒绝局域网权限后提供设置入口。用户可随时退回蓝牙鼠标。

## 2. 画面与操控

| 场景 | iPhone 体验 | 实现约束 |
| --- | --- | --- |
| 纵屏 | 顶部显示 Mac 与当前显示器，中间完整适配桌面，下方提供指针模式、键盘、适合屏幕 | 不拉伸、不裁去菜单栏，画面外的黑边忽略点击 |
| 横屏 | 以画面优先，轻点工具栏按钮可收起控件；退出始终可达 | 旋转或键盘弹出时重新计算可见画面矩形 |
| 直接点选 | 单击定位并左击，双击打开，长按唤出右键；工具栏可开启拖动，下一次抬指结束 | 将触点反算到视频裁剪区域，再映射到所选显示器全局逻辑坐标，包含 Retina 比例与负坐标 |
| 精细操作 | 切换触控板模式，单指相对移动，轻点点击，双指滚动；提供独立左右键 | 复用现有平滑曲线与按下/松开语义，从真实指针位置接续 |
| 放大细节 | 直接模式双指捏合缩放，双指平移视口；触控板模式双指滚动桌面 | 手势按模式互斥；保留一键恢复全画面。VoiceOver 对常用动作提供显式按钮 |
| 切屏或丢帧 | 清除旧帧，标出等待画面，暂时屏蔽绝对点选 | 帧附带显示器 ID 和布局版本，仅接受对应输入；长时间无新帧禁止盲点，断链立即释放拖动 |

正式画面只呈现一个指针。首版可捕获系统指针；若实测延迟明显，再改用独立带时间戳的指针位置叠加，同时关闭捕获光标。

## 3. 键盘和编辑事务

1. 在 Mac 已授权且平台允许的前提下，监听前台应用、聚焦控件及可编辑状态的变化。只传可编辑、不可编辑、敏感或未知及临时焦点标识。只有用户点 Edit Selected Mac Text 后才读取其选区；提交时比对控件、范围及原文，变动后拒绝覆盖或删除。进入普通可编辑框后在 iPhone 打开空白输入栏，允许用户关闭；同一焦点内不反复弹出。
2. 用户在手机完成中文候选、听写、换行、撤销和 Emoji 组合。组合输入期间仅更新本地草稿。「插入到 Mac」明确提交一次，将文本插入当前选区；取消关闭输入栏。焦点变化时冻结草稿并提示重新选择目标。
3. 消息携带会话 ID、一次性提交 ID 和焦点版本。Mac 在执行前重新检查前台应用、目标、敏感状态和版本；重复请求去重。回执区分拒绝、已投递和结果未知；断线不自动重发。普通文字直接输入；加粗、斜体、下划线通过用户确认后的 RTF 粘贴传递，会覆盖 Mac 剪贴板。
4. 「发送消息」或「保存文档」属于目标应用业务行为。首版完成插入后由用户在共享画面点目标应用自己的 Send 或 Save，避免回车在不同应用触发意外操作。
5. 密码框、锁屏、系统认证及敏感输入禁用联动。焦点未知时保留手动草稿，能可靠确认目标后才允许提交；无权限时保持查看或鼠标操作。手动键盘可在不触发远程动作的情况下收起。退出会话清除草稿。
6. 发布门槛为用实际 Mac App Store 沙盒签名配置验证焦点识别与输入注入。Apple 列有跨应用辅助功能和系统打开/保存面板模拟输入限制。即使设置里已授权，也不能据此承诺任意应用都支持。若验证失败，首发只开放已验证能力并调整商店文案。[Apple App Sandbox 限制](https://developer.apple.com/documentation/security/protecting-user-data-with-app-sandbox)

## 4. 技术框架

| 责任 | 首选实现 |
| --- | --- |
| Mac 采集 | ScreenCaptureKit 让用户选择单一显示器，消费 SCStream 有效帧；VideoToolbox 硬编 H.264。首版仅视频；受保护区域遵循系统输出。[Apple ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit) |
| 局域网发现 | Mac 通过 Network.framework 的 NWListener 发布 Bonjour 服务，iPhone 用 NWBrowser 发现。首版使用同一路由网络，支持 Mac 经以太网接入。按系统版本提供本地网络用途说明、Bonjour 服务声明及沙盒网络权限。点对点 Wi-Fi 留作单独的设备兼容性验证。[Apple 本地网络隐私](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy) |
| 身份与传输 | 用现有已认证的配对通道绑定 Wi-Fi 会话公钥指纹和随机挑战，双端验证后建立加密连接；Mac 单独授权本次共享。视频与可靠控制使用独立连接并绑定同一会话。局域网发现名称不作为身份证明 |
| iPhone 播放 | VideoToolbox 解码，按帧时间戳展示。队列有上限，拥塞时降低码率、帧率或分辨率，丢弃过期帧时按需请求关键帧 |
| 输入与退出 | Mac 复用现有鼠标执行器，增加绝对定位及布局版本校验；Wi-Fi 获得输入控制后停止蓝牙控制事件。Mac 菜单显示正在共享的设备、显示器以及停止按钮；撤销配对立即终止会话 |
| 隐私 | 仅在明确发起共享后捕获，不录音、不落盘、不上传。手机进入后台、Mac 锁屏、切换用户或权限撤销时停止捕获和输入，清空最后一帧，重新确认后恢复 |

## 5. 合盖和睡眠

提供可选的「共享期间保持 Mac 唤醒」，用系统电源活动 API 抑制空闲睡眠，仅在会话期间持有，断开、失败和退出时释放。系统睡眠、用户锁屏、内屏关闭和是否有可采集显示器是四种不同状态。无需让内置面板一直亮。

打开盖子时验收长时间空闲采集。合盖使用按 Apple 支持的外接显示器、电源及外接键鼠条件实测，优先共享仍在线的外接显示器。合盖导致显示器移除时立即撤销旧坐标映射；有其他显示器则提示重新选择。无可用显示器或主机休眠时在 iPhone 显示“Mac unavailable. Open the lid or connect an external display.”，保留重新连接入口。无外屏合盖持续图传不列入首版承诺。[Apple 合盖外接显示器说明](https://support.apple.com/en-us/102501)

## 6. 交付顺序与验收

| 阶段 | 验收 |
| --- | --- |
| 本次交互原型 | 单独入口；可关闭返回；编辑示例文本可取消或应用；原鼠标页配对、设置、拖动和暂停回归 |
| 第一阶段：仅查看 | 两台真机使用同一 Wi-Fi，Mac 明确同意后看到真实屏幕；测试拒绝权限、同名设备、网络隔离、权限撤销。初始目标 720p/30 fps，在记录机型与网络的条件下测首帧时间、帧间隔和画面端到端延迟，目标分别为 3 秒内、P95 小于 50 ms、P95 小于 180 ms |
| 第二阶段：画面控制 | 横竖屏、缩放、双显示器及左侧副屏分别点选四角和小按钮；验证拖动中断网能释放；键盘弹出后点击位置仍准确；退回鼠标页正常控制 |
| 第三阶段：输入联动 | 用发布配置测试 TextEdit、Safari 网页表单、聊天输入、密码框、焦点切换以及重复提交；验证中文和 Emoji 完整、未知目标零误写。沙盒能力验证应在第一阶段就开始 |
| 上架前 | 实测打开盖子、合盖接外屏、拔掉电源/外屏、睡眠恢复；记录实际支持的机型和条件。提供英文权限说明、隐私说明、审核双设备操作视频和复现步骤；商店截图只展示上线能力 |

网络质量、自适应码率与弱网操作验收见[共享桌面弱网优化需求](linked-screen-network-quality.md)。
